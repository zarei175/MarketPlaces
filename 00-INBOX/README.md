# 00-INBOX — صندوق ورودی

هر درخواست، نکته، فایل خام یا ماده جدیدی که از کاربر می‌رسد، **اول اینجا** ثبت می‌شود تا هیچ ورودی گم نشود.

## قاعده پردازش
1. ورودی جدید → یک فایل متنی با نام `YYYY-MM-DD-<موضوع>.md` در همین پوشه (محتوا: چه خواسته شده، مشخصات، منبع).
2. پردازش طبق ورک‌فلوی مربوطه در `.brain/WORKFLOWS/`.
3. بعد از پردازش کامل، به ابتدای فایل این خط اضافه شود: `وضعیت: انجام شد (<تاریخ>)` — فایل به‌عنوان سابقه همین‌جا می‌ماند.

## وضعیت‌ها
- `جدید` → ثبت شده، پردازش نشده
- `در حال انجام` → پردازش شروع شده
- `انجام شد (<تاریخ>)` → تمام‌شده
- `مسدود (<دلیل>)` → منتظر چیزی یا در انتظار تأیید کاربر
